Project 1 — Calculator Logic

Variables, Operators, Conditions, and Functions Practice in Dart

Welcome to your first programming logic project! In this project, you will apply fundamental programming concepts—variables, operators, conditional statements, and functions—to build a fully functional console-based calculator in Dart.

🎯 Learning Objectives

By completing this project, you will practice and solidify your understanding of:

Variables & Data Types: Storing numbers, strings, and states (int, double, String, bool).

Operators: Performing arithmetic (+, -, *, /, %), comparison, and logical evaluations.

Control Flow: Using if-else statements and switch-case structures to handle different operations safely (e.g., preventing division by zero).

Functions: Creating modular, reusable blocks of code with parameters and return values.

📋 Project Requirements

Your Dart program should satisfy the following requirements:

Core Operations: Implement functions for at least four basic arithmetic operations:

Addition

Subtraction

Multiplication

Division (with error handling for division by zero)

Advanced Feature (Bonus): Add a modulus or exponentiation operation.

User Interface (Console): Allow the user to input two numbers and choose an operator.

Clean Code: Use descriptive function names, proper type annotations, and clean formatting.



🚀 Extension Challenges (Optional)

If you finish early and want an extra challenge, try adding:

History Log: Keep a list (List<String>) of past calculations and display them when the user types history.

Continuous Loop: Use a while loop so the calculator keeps running until the user types exit.
